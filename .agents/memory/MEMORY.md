# PinPinto 项目记忆

## 版本交付规则

用户于 2026-10-04 明确要求：每次功能变更都必须更新版本，包括本次；升级幅度依据功能轻重。

- 小调整/兼容性修复：补丁版本；新增能力/明显增强：次版本；不兼容变更：主版本。
- 按完整功能交付升版，同一功能的多次提交不重复升级。同步 package、manifest、popup/sidebar 静态徽标；Node 测试检验源版本一致。
- aria2 全入口新能力使用 **1.6.0**（此前为 1.5.14）。已升版的正式发布应显式传 `--version=1.6.0`，不能再默认补丁递增。
- 主版本变更须处理现有发布脚本的 `1.x` 校验限制。远端推送和发布仍必须另行获得授权。

其他事实以 `AGENTS.md`、`docs/aria2.md`、`docs/testing.md` 为准；会话证据放在 `journal/`，不汇入全局记忆。
